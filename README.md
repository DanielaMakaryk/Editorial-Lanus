# Editorial Lanús 📚

Plataforma Web Corporativa e Institucional desarrollada para la gestión de identidad digital y catálogo de la Editorial Lanús.

### 🚀 Características del Proyecto:
* **Diseño Editorial Profesional:** Interfaz adaptada a la estética del sector literario, priorizando la legibilidad y la experiencia del lector.
* **Catálogo Dinámico:** Estructura optimizada para la visualización de publicaciones, novedades editoriales y reseñas.
* **Sección de Contacto:** Sistema integrado para la recepción de manuscritos y consultas comerciales.

### 🛠️ Tecnologías utilizadas:
* HTML5 (Estructuración semántica).
* CSS3 (Estilos avanzados y maquetación responsiva).
* JavaScript puro (Interacciones dinámicas en la interfaz).
